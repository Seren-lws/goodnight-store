# 晚安便利店 · goodnight-store

深夜为你亮灯的小店 —— 睡前故事、白噪音、便签，帮助入眠的 PWA。

## 功能

- 📖 **故事柜**：AI 现场写睡前故事，类型可选，可加自定义设定（开发中）
- 📻 **声音角**：白噪音、轻音乐，可叠加调音量，睡眠定时器自动淡出（开发中）
- 📝 **便签墙**：写下睡前乱七八糟的想法，一键复制，本地存储
- ⚙️ **设置**：填入自己的中转站地址和 API Key，本地存储，不上传

## 技术栈

- Vite + React + React Router
- vite-plugin-pwa（可安装到主屏幕）
- 拟物风 + 新拟态深色主题

## 开发

```bash
npm install
npm run dev
```
